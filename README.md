# Fraud Analytics with SQL

Projeto educacional com dados sintéticos para demonstrar SQL aplicado à prevenção a fraudes financeiras.

## Resultado principal

- 5.008 transações analisadas
- R$ 37.420.783,96 em volume financeiro
- 46 operações P1/P2
- 0,92% da base priorizada
- R$ 490.281,62 em operações P1/P2

> Alerta de risco não significa fraude confirmada.

## Stack

- PostgreSQL
- Supabase
- SQL
- CTEs
- Window Functions
- Git / GitHub
- Power BI (próxima camada)

## Estrutura

- `database/`: schema, dados sintéticos e cenários controlados
- `queries/`: análises fundamentais, investigação, comportamento e score
- `dashboard/`: views para consumo no BI
- `docs/`: documentação complementar
